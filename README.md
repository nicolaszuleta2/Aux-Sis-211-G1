# Auxiliatura de Técnicas de Programación II (SIS-211)

# Programación Orientada a Objetos en Java (POO)

Este repositorio contiene el material trabajado durante las clases y materia de Técnicas de Programación II. El objetivo es ilustrar los conceptos fundamentales de la programación orientada a objetos a través de ejemplos prácticos y organizados por temas.

## 📁 Estructura del Proyecto

### 1. Clases y Objetos
Ejercicios introductorios para comprender cómo definir clases, crear objetos, atributos, métodos y constructores.

### 2. Herencia
Ejemplos que muestran cómo una clase puede heredar de otra para reutilizar código y establecer jerarquías.

### 3. Polimorfismo
Incluye ejemplos de **sobrecarga de métodos** y **sobrescritura**, permitiendo que una misma interfaz tenga múltiples comportamientos.

### 4. Abstracción
Contiene ejercicios con **clases abstractas** y **métodos abstractos**, mostrando cómo forzar a las subclases a implementar ciertos métodos.

### 5. Interfaz Gráfica de Usuario (GUI)
Programas con interfaces gráficas desarrolladas en Java Swing o JavaFX. Se incluyen ejemplos con botones, etiquetas, cuadros de texto y eventos.

### 6. Interfaces
Implementación de **interfaces en Java**, destacando cómo se puede lograr el polimorfismo sin herencia directa.

### 7. Manejo de Archivos
Ejemplos de lectura y escritura de archivos en Java utilizando `File`, `FileWriter`, `BufferedReader`, etc.

### 📂 Ejercicios
Ejercicios adicionales que combinan múltiples temas del curso.

### 📂 Parciales Resueltos
Soluciones de exámenes parciales anteriores con aplicación práctica de los conceptos aprendidos.

### 📂 Programas Básicos
Programas simples para practicar sintaxis, estructuras de control, bucles, arreglos y otros fundamentos de Java.
